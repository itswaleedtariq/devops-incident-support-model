# DevOps Incident Support Model

> **AI-powered DevOps troubleshooting assistant** — Milestone 1: Production Foundation

---

## Project Overview

The DevOps Incident Support Model is an enterprise-grade AI SaaS application that helps on-call engineers diagnose and resolve DevOps incidents faster. Engineers describe an incident in plain language and receive step-by-step remediation guidance generated by a fine-tuned LLM (Qwen2.5-Coder-3B-Instruct) augmented with Retrieval Augmented Generation (RAG).

**Current Status — Milestone 1:** Production-ready backend foundation with clean architecture, logging, configuration management, health endpoints, Docker support, and a full test suite. AI and database layers are not yet integrated.

## Installation

### Prerequisites

- Python 3.11+
- pip 23+
- Docker Desktop (optional)

### 1 — Clone

```bash
git clone https://github.com/your-org/devops-incident-support-model.git
cd devops-incident-support-model
```

### 2 — Create virtual environment

```bash
cd backend
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
```

### 3 — Install dependencies

```bash
pip install -r requirements.txt
```

### 4 — Configure environment

```bash
cp .env.example .env
# Edit .env with your preferred values
```

## Configuration

Environment is selected via `APP_ENV`:

| Value | Description |
|---|---|
| `development` | Debug on, verbose logging |
| `testing` | Used by pytest |
| `production` | Debug off, minimal logging |

All configuration is defined in `backend/app/config/settings.py` using `pydantic-settings`. See `backend/.env.example` for all available variables.
